Spatial data engineering and remote sensing. I also run my own servers, and write most of the tools I use on them.

## Experience

**Chongqing Planning and Natural Resources Information Center** &nbsp;·&nbsp; 2023 – 2025

Worked on the spatial foundation of *Government Affairs · Industrial Land Intelligent Governance*, a municipal platform covering industrial land. Established a unified spatial base in which every industrial park, parcel and enterprise carries a single canonical record, and connected business data that separate departments had been maintaining separately. Built services on top of that base — industrial chain spatial analysis, site selection, remote land inspection, and monitoring of idle land available for reuse — so that a parcel can be followed through its whole lifecycle.

## Projects

**[rui-calendar](https://github.com/vector9584/rui-calendar)**
Self-hosted calendar on Baikal, speaking CalDAV/CardDAV and serving one dataset to web, iOS, Android and Windows clients. React + Electron + PWA, TypeScript throughout.

**[nas-search](https://github.com/vector9584/nas-search)**
Filename search across a whole NAS in milliseconds. A prebuilt SQLite FTS5 index answers queries without touching the filesystem. Pure Python, no third-party dependencies.

**[esp32-epd-photo](https://github.com/vector9584/esp32-epd-photo)**
Four-colour e-paper photo frame on an ESP32-S3 (800×480, JD79665AA). The Python side quantises photos into four-colour C arrays with Atkinson or Bayer dithering and corrects EXIF orientation; the device serves a web page for WiFi setup.

**[nowen-note](https://github.com/vector9584/nowen-note)**
Self-hosted notes with Markdown, mind maps, tasks and full-text search. Fork of [croplfire/nowen-note](https://github.com/croplfire/nowen-note), deployed with a single Docker command.

**[agent-field-notes](https://github.com/vector9584/agent-field-notes)**
Rules I gave an AI agent that operates a real machine, each traced back to the incident that produced it.

**[eco-monitoring-dashboard](https://github.com/vector9584/eco-monitoring-dashboard)**
Single-screen dashboard for regional ecological health assessment in Chongqing, built with plain ECharts and no build step. Undergraduate thesis project, 2023.
