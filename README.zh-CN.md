## 关于

一面做空间数据的 Web 发布与可视化，一面把能搬的服务都搬回自己的机器上自建。

我是从土地业务切进来的，不是从写代码入行。这条线一直在做的是**多源数据的实景三维重建与几何感知**：把无人机倾斜摄影和手持激光扫描融到一起，从融合结果里摘出单体建筑，再按多尺度组织，让整座城的模型一次加载也撑得住。

有意思的从来不是点云本身，而是那道接缝：一个传感器的强项在哪里结束、另一个的又从哪里开始，两者怎么配准才能谁都不被过分信任，以及当整个场景只是一整块 mesh 的时候，"一栋建筑"到底指什么。

### 2021 – 2024 · 硕士论文

《多尺度三维模型一体化表达》，重庆交通大学。

无人机倾斜摄影铺得开，但凡有遮挡，近地细节就没了；手持激光扫描恰好能拍到这些细节，却上不了屋顶，也没法靠人力铺到整片区域。论文把两者融在一起。

- `ICP` 之前先做粗特征匹配，减少配准迭代次数 —— 最终 **RMSE 1.09**
- 用 `SAM` 的文本与点提示提取建筑掩膜，矢量化后绑定属性记录 —— **IoU 0.75**
- `Unreal Engine` 可视化 + HLOD 组织 —— 平均帧数 **+134.78 %**，加载延迟 **−6.25 ms**
- 落到通视、淹没、等高线三类分析

## 项目

### 维护中

- **rui-calendar** — 自建日历服务。一套数据源同时供 Web、iOS、Android、Windows 四端使用，前端 React + Electron + PWA，后端由 Baikal 提供 CalDAV/CardDAV。
  `TypeScript` `React` `Electron` `PWA` `CalDAV`
- **nas-search** — 全 NAS 文件名毫秒级搜索。基于预建的 SQLite FTS5 全文索引，搜索过程不访问文件系统，工具本身零第三方依赖。
  `Python` `SQLite FTS5`
- **esp32-epd-photo** — ESP32-S3 驱动的四色墨水屏相框，800×480，驱动芯片 JD79665AA。Python 端把照片量化到四色，支持 Atkinson、Bayer 两种抖动，并自动校正 EXIF 方向；设备端自带 Web 配网页。
  `C` `Python` `ESP32-S3`
- **nowen-note** — 自建笔记系统：Markdown 笔记、思维导图、任务管理、全文检索。基于 croplfire/nowen-note 分支二次开发，单条 Docker 命令即可部署。
  `Docker` `Markdown` `全文检索`
- **agent-field-notes** — 面向实体设备操控的 AI 智能体落地规则，每条都配着当初踩出它的那次事故。
  `写作` `智能体` `复盘`

### 早期

- **eco-monitoring-dashboard** — 本科毕业设计。重庆市生态健康评估单屏可视化仪表盘，涵盖土地利用、风险源、风险受体等模块；纯 ECharts 实现，无需构建流程。
