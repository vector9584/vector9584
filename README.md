## 项目

### [瑞历 Rui Calendar](https://github.com/vector9584/rui-calendar)

日历、联系人、待办，从云服务商手里拿回来，装进自己的服务器。网页、iOS、Android、Windows 四端读写同一份数据，AI 也能直接往里写日程。

`React` `Electron` `CalDAV` `Docker`

### [nas-search](https://github.com/vector9584/nas-search)

几百万个文件里按名字找一个。预建 FTS5 索引，不靠实时遍历，零第三方依赖。

`Python` `SQLite FTS5`

### [esp32-epd-photo](https://github.com/vector9584/esp32-epd-photo)

照片批量压成四色墨水屏能显示的格式，Atkinson / Bayer 双抖动、EXIF 方向校正，配一个 ESP32-S3 网页配网门户，换图不用改代码。

`Python` `ESP32-S3` `C++`
