One question has run through all three of my degrees: how far can you get from raw measurements to something you can act on?

**Bachelor's** — I built the warning platform behind an ecosystem-health model, so a score computed from fifteen indicators could reach the people who needed it.

**Master's** — I fused drone photogrammetry with handheld laser scans (ICP, RMSE 1.09), pulled individual buildings out of the mesh with SAM (IoU 0.75), and got the whole campus scene running 134.78% faster in Unreal Engine.

**PhD** — the picture stopped being the point. What I care about now is what the data says once the scene exists: spatial analysis, modelling, and the decisions that follow.

### Selected work

**[Rui Calendar](https://github.com/vector9584/rui-calendar)** — a calendar that lives on my own server

One dataset behind four clients: web, iOS, Android and Windows. CalDAV storage, a Chinese-language web client, a desktop overlay, and an assistant that writes events straight into it.

`React` · `Electron` · `CalDAV` · `Docker`

**[nas-search](https://github.com/vector9584/nas-search)** — find one file among millions, by name

A prebuilt FTS5 index instead of crawling the filesystem on every search. No third-party dependencies.

`Python` · `SQLite FTS5`

**[esp32-epd-photo](https://github.com/vector9584/esp32-epd-photo)** — photos on a four-color e-paper panel

Quantizes images into four-color bitmaps with Atkinson or Bayer dithering, corrects EXIF orientation, and ships a web portal for Wi-Fi setup on the ESP32-S3.

`Python` · `ESP32-S3` · `C++`

**[eco-monitoring-dashboard](https://github.com/vector9584/eco-monitoring-dashboard)** — ecological indicators, six panels, one screen

The presentation layer from my bachelor's thesis: land use, risk sources and risk receptors for Chongqing, drawn with plain ECharts and no build step.

`JavaScript` · `ECharts` · `No build step`
